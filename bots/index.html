Source: our own server log of page requests whose browser name (user agent) says it is a bot, such as GPTBot or Googlebot. Bots that pretend to be a normal browser are not counted. Requests: every page or file a bot asked for. Visitors: an estimate of different bots, from a one-way scramble of address and browser name (no addresses are kept). Verified: for Googlebot, Bingbot, GPTBot, OAI-SearchBot and ChatGPT-User we check the visit came from the addresses Google, Microsoft and OpenAI publish; a visit that uses the name from anywhere else is marked unverified. Developer tools such as curl are counted apart, not as bots.
