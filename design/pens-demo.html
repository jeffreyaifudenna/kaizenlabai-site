Draw

A gold pen that turns the homepage into a canvas. Testing how one simple tool can make a page feel alive.

How it was made

HTML canvasPointer EventsSVG cursorClaude~120 lines JS

Recipe

  1. Lay a full-page <canvas> behind the content.
  2. Record pointer points while the button is down.
  3. Smooth them with quadratic curves and stroke in gold.
  4. Brush pen: width follows speed. Nib pen: width follows angle.
  • Zen, Sound, Kaizen and Dev mode each get the same card, numbered as experiments.
